/*
 * USB_MSC_SETUP.txt
 * 
 * USB-MSC Configuration Guide for Noor Audio Player
 * ==================================================
 * 
 * OVERVIEW:
 * ---------
 * This project now supports dual USB functionality:
 * 
 * USB PORT 1 (CDC/UART):
 *   - Serial communication for audio playback
 *   - Existing audio player workflow
 *   - Connect first USB-C cable to ESP32S3
 * 
 * USB PORT 2 (MSC):
 *   - USB Mass Storage Class for SD card access
 *   - Access SD card as removable USB drive on PC/Mac/Linux
 *   - Connect second USB-C cable to ESP32S3
 * 
 * HARDWARE REQUIREMENTS:
 * ---------------------
 * - ESP32S3 microcontroller (has native dual USB support)
 * - 2x USB-C cables (or USB-C hub with 2 ports)
 * - SD card (already in your project)
 * - 2x USB ports on your laptop/computer
 * 
 * FIRMWARE CONFIGURATION:
 * ----------------------
 * Before building, configure ESP-IDF via menuconfig:
 * 
 * 1. Run: idf.py menuconfig
 * 
 * 2. Navigate to: Component config → USB Device (TinyUSB) → USB CDC
 *    - Enable USB CDC mode
 *    - Keep default settings
 * 
 * 3. Navigate to: Component config → USB Device (TinyUSB) → USB MSC
 *    - Enable MSC (Mass Storage Class)
 *    - Set "Use external SPI-connected storage" if applicable
 *    - Keep other defaults
 * 
 * 4. Save and exit
 * 
 * BUILDING THE PROJECT:
 * ---------------------
 * $ idf.py build
 * $ idf.py flash monitor
 * 
 * EXPECTED BEHAVIOR:
 * ------------------
 * On startup, you should see in console:
 * 
 *   USB_MSC: ========================================
 *   USB_MSC: Initializing USB MSC (Mass Storage Class)
 *   USB_MSC: ========================================
 *   USB_MSC: USB device initialized
 *   USB_MSC: SD card mounted via USB MSC at /sdcard
 *   USB_MSC: ========================================
 *   USB_MSC: USB MSC initialized successfully!
 *   USB_MSC: - Connect second USB cable to ESP32S3
 *   USB_MSC: - SD card will appear as removable USB storage
 *   USB_MSC: - Audio playback continues on first USB (UART)
 *   USB_MSC: ========================================
 * 
 * USAGE:
 * ------
 * 1. Connect first USB-C cable to ESP32S3:
 *    - This provides UART communication for audio playback
 *    - Your audio player works as before
 * 
 * 2. Connect second USB-C cable to ESP32S3:
 *    - The SD card will appear as a removable USB storage device
 *    - You can drag-and-drop audio files to the SD card
 *    - Windows: Shows as "Removable Disk"
 *    - Mac: Shows as new volume on desktop
 *    - Linux: Auto-mounts or shows in file manager
 * 
 * IMPORTANT NOTES:
 * ----------------
 * 1. While the USB MSC is actively reading/writing (i.e., you're transferring
 *    files), the audio playback will be paused or interrupted because the
 *    SD card cannot be accessed by both systems simultaneously.
 * 
 * 2. After transferring files via USB MSC, safely eject the USB storage
 *    before resuming audio playback.
 * 
 * 3. Do NOT unplug the first USB cable while audio is playing, as it will
 *    interrupt the playback.
 * 
 * 4. The two USB interfaces are independent:
 *    - Disconnecting the MSC (2nd) cable doesn't affect audio playback
 *    - Disconnecting the UART (1st) cable stops audio playback
 * 
 * TROUBLESHOOTING:
 * ----------------
 * 
 * Problem: Second USB cable not recognized
 * Solution: 
 *   - Ensure ESP32S3 USB is enabled in menuconfig
 *   - Try different USB cables (some cables are power-only)
 *   - Check USB Hub isn't interfering with USB detection
 * 
 * Problem: "USB disconnected" in logs, files won't transfer
 * Solution:
 *   - Check power supply - USB MSC needs more power than UART alone
 *   - Use powered USB hub if using multiple cables
 *   - Verify SD card is properly inserted and mounted
 * 
 * Problem: Audio playback stops when transferring files
 * Solution:
 *   - This is expected behavior - files are transferring, SD card is busy
 *   - Safely eject USB storage when done
 *   - Audio will resume when USB MSC operations complete
 * 
 * Problem: SD card not mounting as USB storage
 * Solution:
 *   - Verify SD card is working first - test audio playback
 *   - Check that USB MSC is enabled in menuconfig
 *   - Look for error messages in console during startup
 * 
 * FILES MODIFIED:
 * ---------------
 * - main/usb_msc.h         (NEW) - USB MSC module header
 * - main/usb_msc.c         (NEW) - USB MSC implementation
 * - main/main.c            (MODIFIED) - Added USB MSC initialization
 * - main/CMakeLists.txt    (MODIFIED) - Added usb_msc.c to build
 * 
 * API FUNCTIONS:
 * --------------
 * bool usb_msc_init(void)
 *   - Initialize USB MSC and expose SD card
 *   - Called automatically in app_main()
 *   - Returns true on success
 * 
 * bool usb_msc_is_connected(void)
 *   - Check if USB is connected to host
 *   - Returns true if USB host detected
 * 
 * bool usb_msc_is_mounted(void)
 *   - Check if MSC is mounted and ready for file transfer
 *   - Returns true if SD card accessible via USB
 * 
 * const char* usb_msc_get_status(void)
 *   - Get human-readable USB MSC status
 *   - Returns status string for logging/display
 *
